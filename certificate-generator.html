📋  How to Use — Bulk Certificate Generator

Generate and email personalised internship certificates in minutes. Follow these 3 simple steps below.

1

📂  Upload Student Data (CSV / Excel)

Prepare a spreadsheet with the following required columns (column names must match exactly):
Student Name  College Name  Domain  Degree  Year  Duration  Start Date  End Date  Place

Optionally add an Email column to enable direct email delivery. Download the sample CSV for the exact format.

Year column note: Enter the student's year of study (e.g. 1st Year, 2nd Year, Final Year). This will appear on the certificate alongside the Degree (e.g. "B.Tech – 3rd Year").

2

🎨  Choose a Certificate Theme

Select from 5 premium themes — Classic Gold, Ocean Blue, Royal Maroon, Forest Green, and Purple Royal. The layout and logos stay consistent; only the colour palette changes.

Click 👁 Preview Certificate to see a live preview of the first student's certificate before generating all files.

3

📥  Generate & Download / Email

Click Download ZIP (PDF) to generate all certificates and download them in a single ZIP file. Each PDF is named after the student.

If your spreadsheet has an Email column, you will be asked whether to send each certificate directly to the student's inbox via Brevo. Emails include the PDF as an attachment.

Use Generate for Event to create certificates with a custom event title instead of the default internship layout.

💡 Pro Tips: Make sure Start Date and End Date are formatted as DD/MM/YYYY or YYYY-MM-DD. The generator auto-calculates duration if the Duration column is blank. For bulk emails, ensure each student's email address is valid — invalid addresses are skipped with a warning in the logs.
